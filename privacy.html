Privacy Policy

Last updated: April 2026

What Data We Collect

  • Resume text — the text you paste into the extension.
  • Profile data — name, email, phone, and other fields you enter for Easy Apply autofill.
  • Job posting data — job title, company, description text (truncated), and metadata scraped from LinkedIn pages you scan.
  • Application records — match scores, status, and notes for jobs you track.

Where Data Is Stored

All data is stored locally in your browser using Chrome's chrome.storage.local API. No data is sent to any server. There is no user account system, no cloud sync, and no remote database.

External Services

This extension makes zero external network requests. No APIs, no analytics, no telemetry. Everything runs locally in your browser.

Tracking & Analytics

This extension does not include any analytics, telemetry, tracking pixels, or usage monitoring of any kind.

Data Sharing

We do not sell, share, or transfer your data to any third party.

Deleting Your Data

You can delete all stored data at any time from the extension's Settings tab using the "Clear All Data" button. Uninstalling the extension also removes all locally stored data.

Permissions

  • activeTab — access the current tab when you click the extension icon.
  • storage — save your resume, profile, and application data locally.
  • scripting — inject content scripts on pages opened before the extension was installed.
  • alarms — schedule the daily check for ghosted applications.
  • notifications — alert you about stale applications.
  • host_permissions (linkedin.com) — read job posting content on LinkedIn pages.

Contact

For questions about this privacy policy, open an issue on the project's GitHub repository.
